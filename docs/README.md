- VERIFICATION.md：实际验证环境和结果。

- FILE_INVENTORY.tsv：实体文件与去重恢复路径。

- legacy/：标明过时的原设计文档。

- DATA_PROVENANCE.md / data_provenance.json：DialMed 公开来源、固定上游提交与逐文件核验。
